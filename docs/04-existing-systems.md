# 4. Existing System Comparison

## 4.1 Selected systems

Four systems were selected. Together they cover the ways viewers currently find and track independent animated web series:

| System | Why it is relevant |
|---|---|
| **YouTube** | Where most independent animation is actually published and watched |
| **IMDb** | The largest general film and TV database with ratings and watchlists; it lists some web series |
| **MyAnimeList (MAL)** | The largest specialised animation catalogue with ratings, lists and recommendations |
| **Fandom wikis** | Fan-made wikis that often hold the most detailed information about a single independent series |

No direct competitor was found, that is, no platform specialised in cataloguing independent animated web series from open platforms. This is why the comparison includes neighbouring categories.

## 4.3 Evidence

Claims in the table must be supported by evidence. Before submission, the team checks each cell on the live service and saves screenshots to `docs/evidence/existing-systems/` with the check date in the file name, for example `imdb-search-2026-10-23.png`. Already supported by documents:

- MAL scope (C1): database guidelines limit entries to professionally produced animation made in Japan, with China and Korea also accepted [S7].
- YouTube recommendations (C8, C9): engagement-driven deep recommender [2]; popularity bias [6, 14].

**Example of an independent series to use in the checks:** *The Amazing Digital Circus* (GLITCH). Check whether it is listed, filterable and rated in each system.

## 4.4 Conclusion

Each system covers part of the need, but none combines (1) a focus on independent web animation, (2) structured metadata with filtering, and (3) legal in-platform watching. AniAtlas fills this gap by combining the catalogue features of IMDb and MAL with YouTube's embed playback. Its distinctive features are side-by-side comparison (C7) and transparent genre-based recommendations (C8).
